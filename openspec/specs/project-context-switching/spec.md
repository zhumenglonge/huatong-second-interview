# 项目上下文切换

## Purpose

建立真正的项目工作区边界，使项目选择能够改变用户看到的任务和实际操作上下文，同时提供与 Biomni 线上页面一致的项目侧栏控件。

## Requirements

### Requirement: 任务必须属于某个项目

系统 MUST 将每个任务关联到一个项目，并将当前项目作为用户当前工作区上下文的一部分暴露出来。

#### Scenario: 不同项目的任务相互隔离

- **当** 用户查看某个项目时
- **那么** 任务列表只能包含属于该项目的任务

#### Scenario: 新任务使用当前项目

- **当** 用户在某个项目下创建任务时
- **那么** 任务必须保存到当前项目，并出现在该项目的任务列表中

### Requirement: 切换项目后刷新工作区数据

系统 MUST 允许用户在可用项目之间切换，并在切换后刷新当前项目的任务数据和当前任务状态。

#### Scenario: 切换到其他项目

- **当** 用户选择另一个项目时
- **那么** 项目标题必须更新，任务列表必须重新加载，旧项目的活动任务流必须停止

#### Scenario: 切换到没有任务的项目

- **当** 用户选择一个没有任务的项目时
- **那么** 任务区域必须显示空状态，且不能继续选中旧项目的任务

### Requirement: 任务操作必须保持项目上下文

系统 MUST 将当前项目上下文应用于任务创建、任务列表和任务相关变更，并拒绝或安全处理指向不可用项目的请求。

#### Scenario: 任务操作使用项目上下文

- **当** 用户发送消息、重试、取消或批准任务时
- **那么** 操作只能作用于当前项目中对应的任务

#### Scenario: 项目不可用

- **当** 客户端请求不存在或不可用的项目时
- **那么** 系统必须返回明确错误，或回退到有效的默认项目，且不能暴露其他项目的任务

### Requirement: 项目侧栏控件与线上布局一致

项目侧栏 MUST 提供项目选择器、可见的项目设置控件和折叠控件，并具备与线上布局一致的无障碍名称和交互状态。

#### Scenario: 项目顶部控件可见

- **当** 侧栏处于展开状态时
- **那么** 项目顶部必须按预期顺序显示项目选择器、项目设置和折叠控件

#### Scenario: 折叠和展开侧栏

- **当** 用户点击折叠控件时
- **那么** 侧栏必须折叠，并提供可见的展开控件以恢复侧栏

#### Scenario: 打开项目设置

- **当** 用户点击项目设置控件时
- **那么** 系统必须打开当前项目的设置界面，且不能改变当前项目或任务选择

### Requirement: 项目设置支持重命名

项目设置 MUST 允许用户修改当前项目名称，并在保存后立即更新项目选择器及后续项目列表中的名称。

#### Scenario: 重命名项目

- **当** 用户在项目设置中提交新的有效名称时
- **那么** 系统必须保存新名称，并在项目选择器中显示新名称

### Requirement: 项目删除受到保护

项目设置 MUST 支持删除项目，但删除必须二次确认；包含任务的项目和默认“快速任务”项目 MUST NOT 被删除。

#### Scenario: 删除空项目

- **当** 用户对一个不包含任务的非默认项目发起删除并完成二次确认时
- **那么** 系统必须删除该项目，并切换到有效的默认项目

#### Scenario: 阻止删除非空项目

- **当** 用户尝试删除包含任务的项目时
- **那么** 系统必须拒绝删除，并提示用户该项目仍包含任务

#### Scenario: 阻止删除默认项目

- **当** 用户尝试删除默认“快速任务”项目时
- **那么** 系统必须拒绝删除，并保持该项目可用
