# 任务总览导航规范

## Purpose

为当前项目提供完整、可检索、可筛选的任务总览，使用户能够浏览全部任务，并从任意任务返回对应会话流。

## Requirements

### Requirement: 任务侧栏支持整体折叠和快速搜索

任务侧栏 MUST 将任务区域整体折叠、新建任务和搜索作为独立控件，并按当前项目任务提供快速过滤。

#### Scenario: 折叠任务区域

- **WHEN** 用户点击任务标题左侧的折叠控件
- **THEN** “等待输入”和“最近”分组及其任务项一起隐藏；再次打开后保留各分组原有展开状态

#### Scenario: 独立创建新任务

- **WHEN** 用户点击新建任务控件
- **THEN** 系统开始当前项目的新任务输入状态，且不改变任务区域展开状态

#### Scenario: 搜索侧栏任务

- **WHEN** 用户打开侧栏搜索并输入查询
- **THEN** 任务列表即时按当前项目任务名称或输入文本过滤，并在无匹配时显示空结果提示

#### Scenario: 打开完整任务总览

- **WHEN** 用户点击任务区域的“查看全部”
- **THEN** 系统在当前项目上下文中打开完整任务总览，而不是只展开“最近”分组

### Requirement: 用户可以打开当前项目的任务总览

系统 MUST 将“查看全部”打开为当前项目范围内的任务总览，并保留当前项目上下文。

#### Scenario: 打开任务总览

- **WHEN** 用户在任务区域点击“查看全部”
- **THEN** 主内容区显示当前项目任务总览，且任务数据只能来自当前项目

### Requirement: 总览显示可操作的任务表格

任务总览 MUST 显示每条任务的名称、状态、最近活动时间和创建时间，并允许用户选择任务。

#### Scenario: 浏览任务元数据

- **WHEN** 用户查看任务总览
- **THEN** 页面显示名称、状态、最近活动和创建时间列，且每行对应当前项目的一条任务

#### Scenario: 从总览打开任务

- **WHEN** 用户点击任务表格中的一行
- **THEN** 系统选中该任务并返回会话流，且会话流加载该任务已有状态和内容

### Requirement: 总览支持搜索和状态筛选

任务总览 MUST 支持按任务名称或输入文本即时搜索，并支持按任务状态筛选；搜索和筛选 MUST 只作用于当前项目已加载的任务。

#### Scenario: 搜索任务

- **WHEN** 用户在总览搜索框输入文本
- **THEN** 表格只显示名称或输入文本包含该查询的任务

#### Scenario: 筛选任务状态

- **WHEN** 用户选择状态筛选项
- **THEN** 表格只显示符合该状态的任务；选择“All statuses”时恢复全部状态

#### Scenario: 没有匹配任务

- **WHEN** 当前搜索和状态筛选没有匹配任务
- **THEN** 表格显示明确的无结果状态，且不显示其他项目任务
