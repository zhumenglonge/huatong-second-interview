# 变更提案

## 为什么要做

本地项目侧栏与 Biomni 线上页面不一致：缺少“项目设置”入口，项目顶部操作按钮也没有完全对齐。更重要的是，目前选择项目只会改变顶部显示的名称，任务、新会话、文件和当前任务状态仍然是全局的。本次变更将项目选择器升级为真正的工作区边界，并同步对齐侧栏控件和布局表现。

## 变更内容

- 在前端任务状态管理和任务 API 中加入明确的项目上下文。
- 持久化每个任务所属的项目，并支持按项目查询任务。
- 只加载当前项目的任务；切换项目时清理或安全转移当前任务及其事件流。
- 新建任务、发送消息及相关任务操作都绑定当前项目。
- 在项目顶部增加“项目设置”入口及对应设置界面。
- 对齐项目顶部控件的顺序、文案、图标、间距、悬停状态和无障碍名称。
- 对齐侧栏折叠/展开，以及任务区、云盘区的折叠交互。
- 增加项目隔离、项目切换和侧栏控件的自动化测试。

## 能力范围

### 新增能力

- `project-context-switching`：项目级任务上下文、项目切换、项目持久化和项目设置入口。

### 修改能力

无。

## 影响范围

- `components/Sidebar.tsx` 和 `app/globals.css`：项目顶部、设置界面和响应式侧栏控件。
- `lib/store.ts` 和 `lib/types.ts`：当前项目状态及按项目加载任务。
- 任务 API 路由和 `lib/db.ts`：项目持久化、筛选和任务创建。
- 切换项目时必须保持现有任务执行和 SSE 流行为正确。
- 需要新增界面测试和集成测试；预计不引入新的外部依赖。
