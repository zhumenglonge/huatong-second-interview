# Spec Delta

## MODIFIED Requirements

### Requirement: 布局配置控制右侧模块

系统 MUST 在中栏顶部提供可访问的“布局”入口，并在布局配置中为待办、结果、计算和笔记提供独立开关。用户首次打开会话工作区时，四个右侧模块默认显示。

#### Scenario: 默认隐藏右侧模块
- **WHEN** 用户首次打开会话工作区
- **THEN** 四个右侧模块均处于显示状态，且每个模块内容默认展开

#### Scenario: 即时打开模块
- **WHEN** 用户在布局配置中打开任一模块开关
- **THEN** 对应模块立即显示；若此前没有模块显示，右侧面板同时立即展开

#### Scenario: 即时关闭模块
- **WHEN** 用户在布局配置中关闭一个已显示模块的开关
- **THEN** 对应模块立即隐藏，其他已打开模块保持显示

#### Scenario: 关闭最后一个模块
- **WHEN** 用户关闭最后一个处于打开状态的模块
- **THEN** 整个右侧面板立即收起，中间会话区恢复为收起前可用的全部剩余宽度

### Requirement: 布局状态与模块内容状态分离

系统 MUST 将模块是否显示与模块内容是否展开/折叠作为独立状态处理。

#### Scenario: 重新打开模块保留内容折叠状态
- **WHEN** 用户关闭一个模块后再次打开该模块
- **THEN** 模块恢复显示，并保留该模块上次的展开或折叠状态

#### Scenario: 面板宽度保持
- **WHEN** 用户拖拽调整右侧面板宽度后收起并重新打开面板
- **THEN** 重新打开时沿用此前保存的面板宽度

### Requirement: 布局控件具备清晰的无障碍语义

布局入口和各模块开关 MUST 暴露稳定、可理解的名称及当前开关状态。

#### Scenario: 读取布局入口
- **WHEN** 辅助技术读取中栏顶部控件
- **THEN** 能识别名为“布局”的按钮，并知道其弹层展开或收起状态

#### Scenario: 读取模块开关
- **WHEN** 辅助技术读取布局配置中的模块控制
- **THEN** 能分别识别“待办”“结果”“计算”“笔记”及其当前开关状态
