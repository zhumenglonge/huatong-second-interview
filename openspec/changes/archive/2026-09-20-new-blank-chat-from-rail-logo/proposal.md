# 变更提案

## 为什么需要

当前 rail-logo 只是装饰元素，点击后不会进入 Biomni 风格的项目级问答入口。用户查看或运行任务后，缺少一个清晰的一键方式来开始新的问题。

## 变更内容

- 将 rail-logo 改造成可访问的交互控件，用于开始新的空白问答会话。
- 清理客户端中当前选中任务的会话状态，并将主内容区切回会话流视图。
- 保留当前项目、历史任务列表和后台任务记录。
- 保留现有输入框，使用户可以立即提交新问题。
- 为 Logo 控件补充聚焦样式和无障碍标签。

## 能力范围

### 新增能力

- `blank-chat-entry`：通过 rail-logo 开始新的项目级空白问答会话。

### 修改能力

无。

## 影响范围

- 影响 `components/IconRail.tsx`、`app/page.tsx` 及相关全局 CSS。
- 复用现有的 `useTaskStore.newTask()` 客户端状态转换，不需要新增 API 接口或持久化模型。
- 后台任务执行逻辑保持不变；点击 Logo 不会取消或删除已有任务。
